# 无线读表器 (MeterReader) - 安卓蓝牙接收程序

## 项目说明

本应用是**2026年全国大学生电子设计竞赛B题**中**电路C**的实现方案——使用安卓手机作为无线读表器，通过蓝牙接收来自"无源"交流电流表的无线模块（电路B）发送的数据。

## 功能特点

### 1. 基本模式（一对一读取）
- 手动选择已配对的蓝牙设备进行连接
- 点击"手动读取"按钮，主动读取电流表数据
- 实时显示电流有效值、设备编号和更新时间

### 2. 自动模式
- 一键启动自动采集模式
- 每2分钟自动采集一次覆盖范围内的电流表数据
- 支持自动搜索多台电流表（根据地址编号区分）

### 3. 报警指示功能
- **低限报警**：电流 < 0.2A 时触发（黄色警告）
- **超限报警**：电流 > 2.0A 时触发（红色警告）  
- **离线指示**：负载断开/蓝牙断开时提示

### 4. 数据存储与查看
- 使用SQLite本地数据库存储，支持掉电保护
- 每条记录包含：读取时间、电流表编号、电流值、是否超限
- 至少存储30条以上记录（实际支持1000条）
- 支持清除历史数据

### 5. 电流趋势曲线
- 使用MPAndroidChart绘制电流变化趋势图
- 显示超限阈值线（2.0A红色虚线）和低限阈值线（0.2A黄色虚线）
- 支持触摸缩放和拖动查看

## 通信协议

无线模块（电路B）通过蓝牙SPP发送数据帧，格式如下：

| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | 0xAA | 帧起始标志 |
| 1 | 地址编号 | 电流表地址 (0-15) |
| 2 | 电流值高位 | (高位<<8 \| 低位) / 1000.0 = 电流值(A) |
| 3 | 电流值低位 | |
| 4 | 状态字节 | bit0=超限, bit1=低限, bit2=离线 |
| 5 | 校验和 | 前5字节累加和 |
| 6 | 0x55 | 帧结束标志 |

## 开发环境

- **IDE**: Android Studio
- **语言**: Java 17
- **最低SDK**: Android 8.0 (API 26)
- **目标SDK**: Android 14 (API 34)
- **构建工具**: Gradle 8.2 + Android Gradle Plugin 8.2

## 构建与运行

### 方法1：使用Android Studio
1. 在Android Studio中打开 `MeterReader` 目录
2. 等待Gradle同步完成
3. 连接安卓手机（开启USB调试）
4. 点击Run按钮运行

### 方法2：命令行构建
```bash
# 在项目目录下执行
./gradlew assembleDebug
# APK生成位置: app/build/outputs/apk/debug/app-debug.apk
```

## 使用说明

1. **首次使用**：确保手机蓝牙已开启，并已与无线模块配对
2. **连接设备**：从下拉列表选择已配对的蓝牙设备，点击"连接"
3. **手动读取**：点击"手动读取"按钮获取当前电流值
4. **自动采集**：点击"自动模式"启动定时采集（每2分钟一次）
5. **查看历史**：点击"历史"按钮查看历史数据和趋势图
6. **报警提示**：异常时会显示红色报警信息

## 注意事项

- 本应用使用蓝牙SPP协议（RFCOMM），需要无线模块支持蓝牙串口协议
- 安卓6.0及以上版本需要位置权限用于蓝牙扫描
- 安卓12及以上版本需要BLUETOOTH_CONNECT和BLUETOOTH_SCAN权限
